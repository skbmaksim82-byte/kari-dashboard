📖 Как работать с дашбордом
📊 Обзор
📊 Главная страница со сводными карточками по всем зонам оформления: Торцы, Витрина, Ювелирный отдел, Антикражные рамки, Кари Хоме, Косметика, Одежда, Зона спорта, Световые таблички, Лайтбоксы, Фасад, Режимник, Корзины, Формат кассы, Зона интернет заказов. Цифра в карточке — количество магазинов с этой зоной.
🖱️ Клик на карточку зоны — открывает детальный список магазинов с фильтром по этой зоне, с возможностью сортировки по столбцам и экспорта в Excel.
⭐ Магазины со статусом ТОП 15 отмечены значком ⭐ в списке слева и в карточке паспорта.
📋 Сводные данные
📋 Полная таблица всех магазинов со всеми атрибутами: регион, подразделение, город, юрлицо, категория, вид, площади, зоны оформления, кассы. Клик по заголовку столбца — сортировка.
🏪 Клик по строке магазина в таблице — открывает его паспорт на вкладке Паспорт магазина.
📊 Кнопка 📊 Выгрузить в Excel — экспорт текущего отфильтрованного списка в файл .xlsx.
🛒 Сводный заказ
🛒 Формирование сводного заказа рекламных материалов (ПОСм) по всем магазинам. Переключайтесь между листами каталога: Листовки, Чек-поинты, Флаги и роллапы, Прочее. Итог суммируется автоматически.
📤 Кнопка экспорта в нижней части — выгрузка сводного заказа в CSV для передачи в работу.
🏪 Паспорт магазина
🏪 Детальная карточка выбранного магазина. Показывает: все зоны оформления с количеством элементов, общую и торговую площадь, формат касс, юрлицо, подразделение, регион.
🗺️ Кнопка 🗺️ Планировка — открывает PDF-план магазина. Управление: колёсико мыши — зум, перетаскивание — смещение, кнопки − + ⛶ — масштаб и вписать в экран, ⬇ Скачать PDF — сохранить файл.
🛒 Кнопка 🛒 Заказ рекламных материалов (режим магазина) — открывает форму индивидуального заказа ПОСм. Отправка — через Excel + Outlook на t.zaharova@kari.com.
✏️ Кнопка ✏️ Сообщить о неточности — форма для отправки корректировок данных паспорта. Сообщение уходит письмом на t.zaharova@kari.com.
📨 Запросы магазинам
➕ Менеджер нажимает ➕ Новый запрос, пишет вопрос и выбирает тип ответа (число, текст, да/нет или выбор из вариантов), затем адресатов: все магазины, подразделения или отдельные магазины.
📬 Магазин при входе видит окно с запросом. Закрыть его без ответа нельзя. Ответы записываются в Google-таблицу на вкладку с названием запроса. Во вкладке «Запросы» видно, кто ответил, и кто ещё нет.
🔍 Поиск и фильтры
🔍 Строка поиска в левой панели ищет по названию, городу, номеру магазина, подразделению и юрлицу. При вводе появляется выпадающий список — выбор из него мгновенно открывает паспорт магазина.
🎛️ Фильтры Подразделение / Категория / Вид / Юрлицо / Магазин работают совместно — каждый дополнительно сужает список. Повторный клик на зону — сбрасывает фильтр.
№ Магазины в списке отсортированы по номеру от меньшего к большему.
☁️ Обновление данных
☁️ Кнопка Обновить в шапке загружает свежие данные из GitHub: таблицу паспорт магазина.xlsx, планировки из папки plans/ и фото из Foto Reklama/. Статус отображается в окне в правом нижнем углу.
📁 Чтобы обновить данные: загрузите новый паспорт магазина.xlsx в корень репозитория GitHub. Планировки — в папку plans/ (имя файла = номер магазина). Фото рекламы — в Foto Reklama/ (имя файла = SKU). После загрузки нажмите Обновить.
🔄 Обновление версии дашборда
🔢 Текущая версия отображается в шапке рядом с названием. При каждом изменении версия увеличивается на 0.01. Нужно обновить в двух файлах одновременно.
1️⃣ В файле index.html — изменить var APP_VERSION = '1.XX' и бейдж в шапке >v1.XX<.
2️⃣ В файле sw.js — изменить var CACHE_VERSION = 'kari-v1.XX'. Это сбрасывает кэш браузера и заставляет приложение загрузить новую версию.
3️⃣ Загрузить оба файла в репозиторий GitHub. Пользователи увидят уведомление с кнопкой Обновить.
